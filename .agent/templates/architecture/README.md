# Product architecture templates

Optional starting points for a **product** repository's `docs/architecture/`.

Rgents is an agent-team framework; it does **not** own or upgrade product architecture docs.

| File | Copied on create to |
|------|---------------------|
| `overview.md` | `docs/architecture/overview.md` |
| `decisions.md` | `docs/architecture/decisions.md` |
| `conventions.md` | `docs/architecture/conventions.md` |

Listed under `product_owned` in `.agent/framework-manifest.yaml`. Upgrade never overwrites them.
Products may delete the folder or reorganize freely.
